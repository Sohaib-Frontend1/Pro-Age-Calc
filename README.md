# Age Calculator Pro

An interactive age calculator that tells you exactly how old you are in years, months, and days.

### Features

- **Precise Calculation**: Calculates your exact age using full birth date `day/month/year`
- **Responsive Design**: Works perfectly on both mobile and desktop
- **Easy to Use**: Just pick your birthdate from the date picker and get instant results
- **Vanilla JS**: Built with only HTML, CSS, and JavaScript. No frameworks or libraries needed

### Technologies Used

- HTML5
- CSS3  
- JavaScript ES6
- Date Object

### How It Works

The app uses JavaScript's `new Date()` to get both the current date and the user's birthdate. 
It then calculates the difference in years, months, and days. The logic also handles edge cases, 
like if your birthday hasn't occurred yet this month or year, to ensure 100% accuracy.

### Purpose

This project was built to practice:
- Working with JavaScript Date objects
- DOM manipulation
- Conditional logic for accurate calculations
- Building clean, responsive UI
